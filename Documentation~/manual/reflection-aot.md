# IL2CPP / AOT 接入注意事项

MFramework 的运行时模块通过显式注册接入，不会扫描程序集或按类名自动创建业务模块。请在入口中注册所需服务，并在使用前明确初始化顺序；参阅 [Core 使用手册](core.md)。

## 自定义代码与第三方 SDK

IL2CPP、小游戏和启用代码裁剪的平台需要特别检查动态访问：

- 使用类型名、字符串或反射访问业务类型时，按目标平台要求配置 `[Preserve]` 或 `link.xml`。
- 自定义序列化器和第三方 SDK 的动态类型、泛型及反射调用，需要由接入方确认其 AOT 与裁剪要求。
- 不要将 Editor 程序集和仅限编辑器的 API 引入 Player 运行时代码。

## 目标平台验证

在目标构建中验证服务注册、配置读取、存档保存与恢复、UI 加载，以及自定义模块和 SDK 的初始化路径。编辑器中的测试通过，不能代替目标平台构建与真机验证。
